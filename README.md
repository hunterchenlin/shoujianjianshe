## 📌 公司与项目简介

本项目为北京首净建设工程有限公司的官方展示系统。首净建设注册于北京市石景山区，是一家**只做北京本地**、资质齐全的专业净化工程公司。系统核心用于展示公司的核心解决方案、工程范围、标准九步流程以及在建工地实拍。

### 🏢 核心解决方案 (按场景定制)
- **实验室净化**：PCR与分子实验室（防串扰）、生物安全实验室（负压气密）、质检研发实验室、屏障动物房（除味梯度）。
- **医疗与工业净化**：医药/生物制品/化药 GMP 车间、医院手术室（GB 50333 分级）与检验科、医疗器械与食品灌装车间。
- **电子洁净厂房**：集成微粒、温湿度、静电、微振动一体化控制系统。
- **在运改造服务**：支持不停产或局部停产的“在运改造”，通过硬隔离与压差控制粉尘与感控。

## 🛠️ 工程与交付范围

系统展示的工程交付物属于核心机电与围护系统，主要包括：
- **围护结构**：墙板、吊顶、型材、门窗、地面及节点密封。
- **空调通风**：风量、风压、温湿度、换气次数、洁净度等环境参数控制。
- **电气与自控**：配电、照明、气锁、压差监测与实时记录。
- **调试与资料**：系统平衡、高效过滤器检漏、检测报告及竣工图。

> ⚠️ *注：消防、压力管道等专项由对应单位出图报审，不默认包含在净化合同内。*

## ⚙️ 标准服务流程 (九步法)

1. **需求沟通** (1–3工作日)：确认场景、等级、改造窗口与投产时间。
2. **现场勘测** (北京1天)：勘测层高、梁柱、电量、冷量、风井及交叉管线。
3. **方案设计** (3–10天)：输出平面、压差、气流及主要系统图。
4. **施工图深化** (1–3周)：出 CAD 施工图，进行管线碰撞检查。
5. **分项报价** (3–7天)：分项列清单，明确拆改、夜间及检测费用。
6. **现场施工** (两周至数月)：围护、机电、自控交叉进行，在运项目分段施工。
7. **综合检测** (1–5天)：测风量、压差、洁净度，进行高效检漏。
8. **资料移交** (1–3天)：交付竣工资料、检测记录，进行操作培训。
9. **后期维保** (定期)：按计划进行巡检、过滤器更换及连锁维护。
